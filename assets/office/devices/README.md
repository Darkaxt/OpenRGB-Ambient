# Device artwork

Six transparent product miniatures generated with the built-in ImageGen tool,
using manufacturer reference photographs. `provenance.json` preserves the exact
prompts, public reference URLs and SHA256 hashes of references and selected
outputs. Reference photographs are not distributed with the application.

The six PNG files and provenance are embedded under `:/office/devices/` and
selected by stable physical ID in `OfficeDeviceIcons.h`. The mixer uses 40px
artwork inside its existing 44px mute target. Full-resolution sources stay here;
the application caches 192px CPU images for DPI scaling.

Images depict Govee H6609 G1 strip, Govee Gaming Light Bars Pro (H8048 driver ID),
Secretlab MAGNUS/MAGRGB desk, Keychron Q6 HE ISO, Lenovo Legion Pro7 16IRX8H and
Logitech G502 X PLUS. These are generated illustrations, not manufacturer photos
or an assertion of manufacturer affiliation.
