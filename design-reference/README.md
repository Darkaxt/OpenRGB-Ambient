# EDAmbilight reference gallery

All ten PNG screenshots from leandor70/EDAmbilight's repository `docs` gallery
were inspected for this revision (2026-11-04). Their original names are retained
except `ss-dashboard`, `ss-topology` and `ss-devices`, renamed `ed-*` locally.
They are retained design inputs, excluded from the installed release package.
The original frontend implementation was also inspected from the shipped v1.2.0
release. See `EDAMBILIGHT-GUI-REVIEW.md` for provenance and functional reconciliation.

The 2026-11-04 corresponding-page audit found that functional reconciliation did
not establish visual parity. See [VISUAL-PARITY-CHECKLIST.md](VISUAL-PARITY-CHECKLIST.md)
for each recorded difference, exact page correspondence and the original font/
icon catalogue. Modern `ss-*` references are the main target; historical
`screenshot-*` variants are recorded separately. The current native UI has not
passed that visual gate. [Recovered icon sheet](iconography/contact-sheet.png).
